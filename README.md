# Hearth

A homeowner document and knowledge management app. Helps homeowners organize, understand, and act on information about their homes — combining document ingestion (receipts, permits, manuals, photos, video) with proactive education about home systems, maintenance, and risks they don't know to ask about.

## Stack

- Next.js 15 (App Router) + TypeScript
- Tailwind CSS
- Supabase (Postgres, Auth, Storage)
- Deployed on Vercel

## Development

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).
